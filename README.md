🍴 Recipe App

The Recipe App is a simple web application that allows users to search for meals and recipes using the TheMealDB API. It provides recipe details such as dish name, cuisine type, category, and an option to view full recipe instructions.

🚀 Features
1. When No Input is Entered

If the user clicks Search without typing anything, the app shows a message:
👉 “Type the Meal in the search Box!!”

If the user types a dish name that is not available in the database, the app shows:
